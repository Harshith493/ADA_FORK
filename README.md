# FORK Project

Calibrated scenario forecasting with the frozen Chronos‑Bolt foundation model. The repository contains code, results, and a Streamlit demo.

## Demo
Run the demo with:
```
python -m streamlit run app\demo.py
```

## Documentation
See `docs/RUNBOOK.md` for usage instructions.

## Data
Raw data is not included in this repo. Refer to `docs/RUNBOOK.md` (or `deliverables/dataset/DATASET.md` if present) for information on obtaining the dataset.
